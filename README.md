## Changes from the original

See the commit history for the exact diffs. In short:

- Added a Below Zero build from the same source.
- Replaced DOTween with a coroutine for the smooth rotation (Below Zero doesn't ship DOTween).
- Changed the plugin GUID and namespace so this build doesn't masquerade as the original.
